# 普通节点

这个示例展示了 G6 Vue 扩展的基础用法，创建一个简单的图形结构。

## 功能特性

- **基础图形**: 创建包含节点和边的简单图形
- **交互支持**: 支持拖拽元素交互
- **生命周期管理**: 演示图形的渲染和销毁回调
- **简洁配置**: 最小化配置展示核心功能

## 主要实现

- 定义两个基础节点，包含标签文本
- 创建节点间的连接边
- 启用拖拽行为增强交互体验
- 添加渲染和销毁事件监听

## 适用场景

- 快速原型开发
- 基础图形展示
- 学习 G6 基本概念
- 简单的关系图表
