# 系统性能诊断流程图

这个示例展示了如何使用 G6 Vue 扩展创建复杂的业务流程图，以系统性能诊断为例。

## 功能特性

- **复杂流程图**: 展示多步骤的诊断流程
- **自定义节点类型**: 根据不同阶段使用不同的节点样式
- **动态数据加载**: 从远程 API 获取流程数据
- **交互高亮**: 鼠标悬停时高亮相关节点和边
- **自适应布局**: 自动调整视图以适应内容

## 主要实现

- 使用 `PerformanceNode` 组件渲染不同类型的诊断节点
- 实现自定义的悬停激活行为
- 支持多种节点类型：预检查、问题、检查、解决方案
- 使用折线边连接流程步骤
- 动态调整节点大小和位置

## 适用场景

- 业务流程图
- 系统架构图
- 故障诊断流程
- 工作流程管理
- 决策树可视化
