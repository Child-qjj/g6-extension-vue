# 自定义 Vue 节点

这个示例展示了如何使用 G6 Vue 扩展创建自定义的 Vue 组件作为节点，展示了如何将 Vue 组件与 G6 图形系统集成。

## 功能特性

- **自定义 Vue 组件**: 使用 Vue 组件定义节点的外观和行为
- **数据绑定**: 节点数据与 Vue 组件的 props 进行绑定
- **事件处理**: 支持节点的点击、悬停等事件
- **动态更新**: 节点数据变化时，组件会自动更新

## 主要实现

- 定义一个自定义的 Vue 组件 `VueNode`
- 使用 `VueNode` 组件创建 G6 节点
- 实现节点的点击事件处理
- 动态更新节点数据

## 适用场景

- 复杂的节点渲染需求
- 自定义节点交互行为
- 数据驱动的节点展示
