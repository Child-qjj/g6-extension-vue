# 英格兰阵容

这个示例展示了如何使用 G6 Vue 扩展创建一个足球队阵容图，以英格兰队为例。

## 功能特性

- **自定义 Vue 节点**: 使用 `VueNode` 扩展创建球员卡片节点
- **背景图片**: 添加足球场背景图片，增强视觉效果
- **数据驱动**: 从 JSON 文件加载球员数据
- **位置布局**: 根据球员在场上的位置进行精确布局
- **响应式设计**: 支持不同屏幕尺寸的适配

## 主要实现

- 使用 `PlayerNode` 组件渲染每个球员的信息卡片
- 通过坐标转换将逻辑位置映射到实际显示位置
- 集成背景插件显示足球场地图
- 支持球员信息的动态展示

## 适用场景

- 体育数据可视化
- 团队组织架构展示
- 位置关系图表
- 游戏角色布局
